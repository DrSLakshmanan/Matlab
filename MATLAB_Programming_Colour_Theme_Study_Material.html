Module 1: Introduction 6Hrs + 3Hrs | CO-1 | BTL-2

MATLAB stands for MATrix LABoratory. It is a high-level programming language and interactive environment developed for numerical computation, data analysis, algorithm development, visualization, and simulation. MATLAB is widely used in engineering, mathematics, physics, finance, machine learning, control systems, signal processing, and image processing.

The most important feature of MATLAB is that it treats data as matrices and arrays. Even a single number is considered a \(1 \times 1\) matrix. This makes MATLAB particularly suitable for solving linear algebra problems, performing numerical calculations, and working with large sets of data.

Features of MATLAB

  • Easy to learn: MATLAB uses simple English-like commands and mathematical notation.
  • Powerful mathematical tools: It provides built-in functions for algebra, calculus, statistics, linear algebra, and numerical methods.
  • Excellent visualization: MATLAB can create 2D plots, 3D surfaces, histograms, bar charts, pie charts, and animations.
  • Matrix-based computation: Matrix and vector operations can be performed directly without writing long loops.
  • Programming support: MATLAB supports variables, conditional statements, loops, functions, and file handling.
  • Toolboxes: Specialized toolboxes are available for signal processing, control systems, image processing, machine learning, and communications.
  • Simulink support: Simulink allows graphical modelling and simulation of dynamic systems.

MATLAB environment

When MATLAB starts, it displays several main windows. Understanding these windows is essential for working efficiently.

Command Window
This is the main area where MATLAB commands are typed after the prompt >>. The result of a command is displayed immediately.
Workspace
Shows all variables currently stored in memory. It displays variable name, value, size, bytes used, and class.
Current Folder
Displays files and folders in the current working directory. MATLAB searches for script and function files here.
Command History
Keeps a record of commands entered earlier. A command can be reused by double-clicking it.
Editor
Used to create, edit, save, debug, and run MATLAB program files with the extension .m.
Figure Window
Displays graphs, plots, images, and visual results created by MATLAB.
Help Browser
Provides detailed documentation, examples, and search facilities for MATLAB functions.
Details Panel
Shows additional information about selected files or variables.

Script files

A script file is a MATLAB program saved with a .m extension. It contains a sequence of commands that can be executed together. Scripts are useful for calculations that need to be repeated or modified.

% Program to calculate the area of a circle

radius = 7;
area = pi * radius^2;

fprintf('Radius = %.2f\n', radius)
fprintf('Area = %.4f square units\n', area)

switch-case statement

The switch-case statement is useful when a single variable must be compared with several possible values.

day = 4;

switch day
    case 1
        fprintf('Monday\n');
    case 2
        fprintf('Tuesday\n');
    case 3
        fprintf('Wednesday\n');
    case 4
        fprintf('Thursday\n');
    otherwise
        fprintf('Invalid day\n');
end

Loops

A for loop repeats statements for a known number of iterations. A while loop repeats as long as its condition remains true.

% Sum of first n natural numbers
n = 10;
total = 0;

for k = 1:n
    total = total + k;
end

fprintf('Sum of first %d numbers = %d\n', n, total);
% Factorial using while loop
n = 5;
fact = 1;
k = 1;

while k <= n
    fact = fact * k;
    k = k + 1;
end

fprintf('Factorial of %d = %d\n', n, fact);

Function files

A function file contains reusable MATLAB code. The function name should generally match the file name. Inputs are passed through parentheses and outputs are returned to the calling program.

% File name: area_circle.m
function area = area_circle(radius)
% AREA_CIRCLE calculates the area of a circle.

area = pi * radius^2;
end

if a > b
    larger = a;
else

end
end

Module 5: Numerical Analysis & Simulink 6Hrs + 3Hrs | CO-5 | BTL-3

Numerical analysis uses computational methods to solve mathematical problems that may be difficult or impossible to solve exactly. Common applications include polynomial evaluation, curve fitting, interpolation, root finding, and solving equations. Simulink extends MATLAB by providing a graphical environment for modelling and simulating dynamic systems.

Polynomials

MATLAB represents a polynomial using a vector of coefficients in descending powers of \(x\). For example, \(2x^3+3x^2-x+5\) is represented as [2 3 -1 5].

p = [2 3 -1 5];

% Evaluate polynomial at x = 2
value = polyval(p,2)
% value = 31

% Find roots
r = roots(p)

Curve fitting

Curve fitting finds a mathematical function that best represents a set of data points. Linear fitting finds the best straight line. Polynomial fitting fits a polynomial of a selected degree.

x = [1 2 3 4 5];
y = [2.1 4.0 6.2 8.1 9.9];

% Linear fit: y = m*x + c
p = polyfit(x,y,1);
fprintf('Slope = %.4f, Intercept = %.4f\n', p(1), p(2));

% Plot original data and fitted line
xfit = linspace(1,5,100);
yfit = polyval(p,xfit);

plot(x,y,'ro','MarkerFaceColor','r')
hold on
plot(xfit,yfit,'b-','LineWidth',2)
legend('Data','Linear fit')
xlabel('x')
ylabel('y')
title('Linear Curve Fitting')
grid on

Interpolation

Interpolation estimates values between known data points. Unlike curve fitting, interpolation normally passes exactly through the given data points.

x = [1 2 3 4 5];
y = [2 4 6 8 10];

% Linear interpolation at x = 2.5
yi = interp1(x,y,2.5)
% yi = 5

% Spline interpolation
yi_spline = interp1(x,y,2.5,'spline')

Basic Fitting interface

After plotting data, open Tools → Basic Fitting in the MATLAB figure window. This interface allows you to choose linear, quadratic, cubic, or higher-order polynomial fits, display the fitted equation, plot residuals, and evaluate the fit at selected points.

A higher-degree polynomial may fit the sample points closely but may behave poorly between or outside the data range. This is called overfitting.

Introduction to Simulink

Simulink is a MATLAB-based graphical environment for modelling, simulating, and analysing dynamic systems. Instead of writing every equation as code, users connect blocks that represent inputs, mathematical operations, systems, and outputs.

Sources
Provide input signals, such as Step, Sine Wave, Ramp, and Constant.
Math Operations
Perform addition, subtraction, multiplication, gain, and other calculations.
Continuous
Model differential equations and dynamic systems, such as Integrator and Transfer Fcn.
Sinks
Display or store outputs, such as Scope, Display, and To Workspace.
Logic and Bit Operations
Perform logical and switching operations.
Signal Routing
Route, combine, or split signals using blocks such as Mux and Demux.
